# Project 50 - Open Source Issue Triage and Developer Assignment Tool

## Overview

This project is being developed as part of the Design and Analysis of Algorithms (DAA) Project-Based Learning assessment.

The aim is to build a C-based tool for managing software issues by prioritizing tasks, searching issue records, planning work based on available resources and dependencies, and assigning issues to suitable developers.

Relevant DAA algorithms will be integrated into the actual product functionality. The remaining mandatory syllabus algorithms will be implemented and demonstrated separately through an Algorithm Workbench within the same project.

## Implementation

- Language: C
- Standard: C11
- Compiler: GCC
- Interface: Menu-driven CLI
- Build System: Makefile

## Planned Core Features

- Load and view software issues
- Load and view developer records
- Prioritize issues
- Search issues
- Plan work based on available resources
- Assign issues to suitable developers
- Represent issue dependencies
- Compare relevant algorithmic strategies

## DAA Coverage

The project will include implementations from the following areas:

- Sorting and searching
- Divide and conquer
- Greedy methods
- Dynamic programming
- Graph algorithms
- Backtracking and branch and bound
- Flow and matching
- String matching
- Number theory
- Algorithm analysis

## Development Plan

The project will be developed in two evaluation phases.

### Phase I

Develop the working foundation of the issue-triage system, including the data model, input handling, CLI, issue prioritization, searching, basic planning and assignment, testing, and initial algorithm comparisons.

### Phase II

Complete the mandatory DAA algorithm implementations, Algorithm Workbench, advanced optimization and assignment algorithms, benchmarking, testing, complexity analysis, and final demonstration scenarios.

## Current Scope

The current version focuses only on the requirements of the DAA PBL and internal evaluation.

Features such as live GitHub integration, databases, machine learning, web deployment, and other portfolio-oriented extensions are outside the current assessment scope.
